Contas da Shopee

No dia a dia o robô não usa nada disto: as contas já estão conectadas dentro dos perfis do AdsPower, e ele só abre e lê. Isto aqui é para quando uma sessão cai. Aí ele precisa entrar como você entraria, e para isso precisa de três coisas, nesta ordem:

  1. O e-mail da conta. Ele não guarda 80 e-mails: monta cada um a partir do número da conta, seguindo o padrão que você define abaixo.
  2. A senha. A mesma para todas as contas.
  3. O código que a Shopee manda por e-mail depois da senha. Para ler esse e-mail, ele usa um serviço de caixa de entrada — a terceira chave.

Se faltar qualquer uma, o robô não consegue entrar: a conta vai para a etapa 3 esperando você.

Falta preencher para o robô conseguir rodar:
2 · A senha
Guardada neste computador
Fica num arquivo que só o seu usuário deste computador consegue abrir. Ela nunca sai daqui, e nunca volta para esta tela depois de salva.
3 · O código que a Shopee manda por e-mail
Guardada neste computador
Ao entrar, a Shopee manda um código para o e-mail da conta. O robô precisa abrir essa caixa de entrada para ler o código — e quem faz isso é um serviço chamado RapidAPI. Esta é a chave dele.
